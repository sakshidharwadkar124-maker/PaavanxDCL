#PavanXDCL Landing Page Clone
A responsive landing page inspired by the PavanXDCL website, built using pure HTML and CSS.

#Features
- Responsive design
- Dark-themed modern UI
- Navigation bar
- Call-to-action buttons
- Hover effects
- Pure HTML & CSS

#Technologies Used
- HTML5
- CSS3

#Purpose
This project was created to practice front-end web development skills including:

- HTML page structure
- CSS styling
- Flexbox layouts
- Responsive design
- Modern UI development
